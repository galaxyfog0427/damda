# ADR-0001: 프로젝트 주제로 무료 템플릿 모음 사이트를 고른다
 
- 날짜: 2026-11-05
- 상태: 승인 (2026-11-05, 정현)
- 작성: 초안은 멘토 AI, 검토·승인은 정현
## 맥락
 
- 취업(이력서·포트폴리오)을 위한 두 번째 프로젝트다. 직전 프로젝트 board는 학습 순서대로 기술을 붙였고 배포는 하지 않았다.
- 이번에는 공개 URL에서 상시 가동하는 **실 운영**을 한다. PG로 실제 결제를 받으려면 사업자 등록 등이 필요하므로, **결제 없이 운영할 수 있는 주제**여야 한다.
- 부하 테스트, 모니터링, 개선 기록의 대상이 되도록 **동시성·트래픽 문제가 도메인에서 자연스럽게 생겨야** 한다.
- 12월 전에 지원할 수 있는 v1이 필요하다(약 4주, 11월 중순~12월 초에 기말 프로젝트가 겹친다). 운영은 서버 한 대(NCP)에서 한다.
## 선택지
 
| 후보 | 좋은 점 | 버린 이유 |
| --- | --- | --- |
| 홈쇼핑 (방송 특가) | 재고 동시성, 주문 이벤트, PG 테스트 결제로 외부 연동 | 결제가 핵심 기능인데 실제 결제를 할 수 없어 데모로만 운영된다. 실제 사용자가 생길 수 없고, 4주에 하기엔 넓다 |
| 수강신청 연습장 | 정각에 몰리는 트래픽이 도메인 그 자체, 개인정보 부담이 낮다 | 수요가 1~2월에 몰리고, 외부 API·Kafka를 쓸 근거가 약하다 → 시즌에 맞춰 다음에 다시 검토 |
| 행사 선착순 신청 | 정원·대기자 승급 경합, 알림·Kafka가 자연스럽다 | 실제로 써 줄 주최 단체가 없다 |
| 실시간 투표·퀴즈 | 동시 접속, K8s를 넣을 근거 | 실시간 푸시를 새로 배워야 해 4주가 빠듯하고, 외부 API·Kafka 근거가 약하다 |
| **템플릿 모음 사이트** | 아래 "결정" | — |
 
## 결정
 
노션·PPT 템플릿을 무료로 받을 수 있는 사이트를 만든다. 일부 템플릿은 **드롭**으로 연다. 드롭은 정해진 시각에 열고, 수량·기간 조건 안에서만 라이브러리에 추가할 수 있게 하는 이벤트다.
 
이유:
1. 무료 디지털 상품이라 결제 없이도 실제 사용자가 실제로 받아 갈 수 있다. 실 운영이 성립한다.
2. 둘러보기 → 라이브러리에 추가(내부적으로는 주문) → 다운로드 흐름이 커머스와 같아서, 커머스 회사 면접에서도 설명하기 쉽다.
3. 트래픽 모양이 두 가지다. 읽기가 많은 카탈로그(목록·검색·정렬)와, 쓰기가 한순간에 몰리는 드롭(수량 초과 발급 방지)이다.
4. 결제와 배송이 없어서 4주 v1 크기로 줄일 수 있다.
5. 정현이 직접 해 보고 싶은 주제였고, 노션 템플릿을 찾아본 경험이 있다.
## 결과
 
지킬 규칙과 감수하는 것:
- **사용자는 거의 없다고 가정한다.** 트래픽 검증은 부하 테스트로 하고, 문서에는 가상 시나리오라고 밝힌다. 사용자가 없어도 공개 서버 운영(배포, 인증서, 디스크, 봇 요청, 알림)은 실제로 겪는다.
- **수량 제한은 "선착순 드롭"으로 정의한다.** 막는 것은 파일 복사가 아니라, 이 사이트에서 정해진 수보다 많이 발급되는 것이다.
- **저작권**
  - 파일로 올리는 것은 직접 만든 템플릿뿐이다. 남이 만든 템플릿(노션 공식 템플릿 등)은 다시 올리지 않고 원본 페이지 링크로만 연결한다. 노션 갤러리의 재배포 조건은 [확인 필요].
  - 직접 만든 템플릿이라도 안에 든 폰트·이미지·아이콘은 각자 라이선스가 있으므로, 재배포가 허용된 것만 쓴다(예: OFL 폰트).
- **콘텐츠 제작이 별도 작업으로 생긴다**(공개 기준 20개, 목표 50개). 개발 시간, Claude Pro 사용량과 겹친다.
- **MCP 서버는 넣지 않는다(보류).** 원하는 AI 기능은 사이트 안 챗봇이고, MCP는 4주 v1에서 들이는 비용에 비해 효과가 작다. 챗봇이 쓰는 도구를 서비스 계층 위에 만들어 두면 나중에 MCP로 여는 것은 어렵지 않다. 10/28에 세운 "AI 에이전트 경험" 목표는 프론트 AI와 리뷰어 AI를 지휘하는 것으로 채운다.
## 다시 검토할 때
 
- 수강신청 연습장: v1 이후 1~2월 시즌을 보고 다시 판단한다.
## 정현의 판단 (대화에서 옮김)
 
> 정현의 말을 대화에서 옮겼다. 읽기 쉽게 조금 다듬었지만 뜻은 바꾸지 않았고, 정현이 말하지 않은 이유는 넣지 않았다. 이 칸은 11/5 규칙을 도입할 때 덧붙였고, 결정 내용은 그대로다.
 
- **주제** (11/4): "처음에 홈쇼핑은 그저 연습용 프로젝트로 떠올린 것이었는데, A로 해 보고 싶긴 해요. 여러 템플릿(노션, PPT 등)을 무료로 다운로드할 수 있는 템플릿 모음 사이트를 실 운영의 첫 번째 프로젝트로 해 보고 싶었습니다."
- **트래픽 검증** (11/4): "선착순으로 풀리는 템플릿 등으로 동시성 트래픽을 볼 수 있겠지만, 실 운영에서는 유저가 거의 없다시피 할 테니 이런 부분은 부하 테스트로만 검증할 수 있을 것 같습니다."
- **수강신청 연습장** (11/4): "B도 이 프로젝트가 끝나면 시기에 맞춰 만들어 보는 것도 괜찮겠네요."
- **AI 기능과 MCP** (11/4): "우리 사이트 안에서 AI 챗봇 같은 걸 생각했었습니다. 우리 프로젝트에 MCP를 쓰게끔 해 보려는 생각은 없었습니다. 당장 면접에 도움이 크게 안 된다면 더 그렇고요."
- **동기** (11/4): "노션 템플릿을 찾아보던 경험은 있습니다."
- **노션 공식 템플릿** (11/5): "템플릿 썸네일 같은 것만 올리고, 다운로드 버튼 대신 노션으로 가는 링크를 두면 될 것 같네요."
- **템플릿 수** (11/5): "있어 보이는 정도로 50개 정도는 어떨까요. 하면서 되면 계속 추가해 보죠."
